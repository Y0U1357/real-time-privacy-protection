# Architecture

## Browser-local pipeline

```text
getUserMedia / local video
        ↓
CameraSource (web/js/camera.js)
        ↓
PersonDetector (web/js/detector.js)
        ↓
YOLOX decode + NMS (web/js/yolox.js)
        ↓
ByteTrack (web/js/tracker.js)
        ↓
StableIdManager (web/js/stable-id.js)
        ↓
Padding + Privacy Hold
        ↓
Pixelator (web/js/privacy.js)
        ↓
Renderer (web/js/renderer.js)
        ↓
Canvas
```

## Application lifecycle

`web/js/app.js` owns the browser lifecycle:

- one `requestAnimationFrame` loop;
- at most one inference in flight;
- source switching without an inference queue;
- pause/resume and local-video timeline handling;
- epoch-based rejection of stale inference after stop, source changes, or seek;
- ByteTrack → Stable ID → privacy rendering order;
- dashboard metrics and controls.

If inference is slower than the media source, new detector starts are skipped until the active inference completes.

## Model/runtime

`web/js/detector.js` loads `web/models/yolox_s_mot17.onnx` through ONNX Runtime Web.

```text
WebGPU
  ↓ fallback
WASM
```

Runtime assets are generated by `tools/setup_ort_web.py`. The ONNX model is generated by `tools/export_yolox_onnx.py`.

## Tracking

`web/js/tracker.js` is the browser ByteTrack implementation with Kalman prediction and staged association.

Stable ID is a short-term geometric reassociation layer. It is not ReID or person recognition.

## Privacy

Defaults live in `web/js/config.js`:

- padding: 5%;
- pixel scale: 8%;
- privacy hold: 5 detection ticks;
- block pixelation by default;
- optional palette/dithering Pixel Art mode.

Privacy hold extends masking across short detector/tracker gaps but does not guarantee complete anonymity.

## Local media and network boundary

Local files are read through `blob:` URLs. Raw media is not sent to an application backend. `web/js/network-guard.js` records browser network activity for diagnostics.

## Python support scope

Python is retained only for:

- exporting/validating YOLOX-S MOT17 to ONNX;
- downloading the pinned ONNX Runtime Web distribution;
- serving the local static demo;
- WildTrack evaluation.

There is no Python/FastAPI runtime in the product path.
